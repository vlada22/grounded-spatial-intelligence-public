# Upstream model references

The published Article 02 experiment used recorded outputs from these upstream model families:

- Depth Anything 3 — https://github.com/ByteDance-Seed/Depth-Anything-3
- Segment Anything 3 — https://github.com/facebookresearch/sam3
- Hugging Face Transformers SAM 3 video integration — https://huggingface.co/docs/transformers/model_doc/sam3_video

This public repository does **not** redistribute model checkpoints or gated runtime material. It contains only project-authored presentation code and compact derived measurements from the reviewed experiment. Consult each upstream project for its current license and model terms.
